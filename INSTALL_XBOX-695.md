# Twilight Princess Randomizer 1.4.1.695 — Xbox/UWP

.695 fixes the exact Start Randomizer activation error exposed by .694.

Observed Xbox failure:
- Seed generation and runtime seed parsing both completed.
- Start Randomizer failed while registering a native message override.
- The failing record was group 9, message id 25544, language 1.
- Dusklight/Twilight Princess message resources support common group 0 and stage groups 1-8, so group 9 is not a valid native message group.

Fix:
- New seeds no longer serialize native text overrides with impossible group IDs.
- Runtime activation also skips invalid group >= 9 records, so a seed generated by .694 can still be selected.
- Valid groups 0-8 are unchanged.
- .694's detailed activation diagnostics remain enabled.
- .693's seed parser/key-width fixes remain enabled.
- Full generator certification and runtime seed round-trip validation remain mandatory.

Audio:
- Xbox/UWP audio remains on the proven-safe disabled path while the main01.audio-execute deadlock is investigated separately.
