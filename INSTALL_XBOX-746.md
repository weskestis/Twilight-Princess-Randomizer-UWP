Xbox UWP 1.4.1.746

Install `TwilightPrincessRandomizer_1.4.1.746_x64.msix` through Xbox Device Portal in Developer Mode. Use an update installation to retain the existing app's saves, data location and mod settings.

This build keeps Dusklight 2.0.1 and all .744/.745 runtime fixes, source-built mods, appearance randomization and run overlays.

The Mods list now defers detail/banner/control construction while focus moves quickly. When focus settles, the selected preview appears. A or right opens the selected mod immediately. Off-screen list rows keep their controller order and scroll positions while skipping icon loading and updates. Action buttons cannot change a mod from an old preview.

Console frame-rate validation is pending. The production UI fixture exercises the actual ModsWindow, Pane, controls, image decorator and pinned RmlUi engine at 720p, 1080p and 4K; it is not an Xbox GPU benchmark.

Appearance options: Colors / Cosmetics > Cosmetics > Randomize Appearance. Run overlays: Settings > Interface > Transparent Run Overlays, with independent visibility, scale and horizontal/vertical position. The death counter remains red and reads the current save. The game timer remains active simulation time, independent of a 120 FPS render cap.

Crests of Courage, A Link Between Twilight and MFB Multiplayer retain signed source ports. MFB/Crests can receive voice; Xbox microphone input remains unavailable. Standalone Zora Swim, Ragdoll, Dark Morpheel and hopex Dark Link still need rebuildable author source.
