# Fierce Deity hair — Xbox test build 1.4.1.746

Install the signed MSIX over the existing Twilight Princess Randomizer app.
Keep the existing game image, save data and settings.

Import the two updated Fierce Deity appearance `.dusk` files through Mods →
Import, or upload them to the app's
`LocalState/TwilitRealm/Dusklight/mods` folder through Xbox Device Portal.
Enable **one** Link appearance. Enable **Fierce Deity Hair Physics** for the
enhanced movement. Fully quit and restart the app after changing appearances.

The game supplies Link's original archive. Only the hair model is replaced;
the face and outfit textures from the refined mods are retained. No original
asset export or extra game-image upload is required.

This is a console test package. Local mesh, skinning, material, package and
solver checks pass. Console appearance, clipping, animation and performance
still require testing.
