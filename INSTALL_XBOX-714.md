# Twilight Princess Randomizer 1.4.1.714 — Xbox/UWP

This build keeps the working mod/asset path and restores the custom Pure Item Tracker from the later .649 design.

- Restores **Pure Item Tracker V3** as the Ship-style transparent six-column icon grid.
- Tracker is enabled by default while a Randomizer seed is active.
- Owned icons are full color; unowned icons stay visible at 20% alpha.
- Progressive counts are shown as outlined text below icons.
- Tracker settings include UI scale, icon size, column count, lock position, and reset layout.
- Tracker inventory is sourced from the active Randomizer save through the current split Randomizer module.
- Keeps the non-blocking Start Randomizer correction, per-save seed consumption, transition recovery, reset audio guards, Cosmetics access, mods, DVD overlays, and texture replacements.
