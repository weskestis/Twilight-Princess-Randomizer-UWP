# Twilight Princess Randomizer 1.4.1.757 for Xbox

Install the x64 MSIX over 1.4.1.756 in Xbox Device Portal. If Device Portal asks for a dependency, select Microsoft.VCLibs.x64.14.00.appx. The update uses the existing package identity and save location.

Open Mods to enable Crests of Courage or Twilit Essentials. Crests of Courage is built from the author's 1.10.1 source. Every co-op player should use Crests 1.10.1.

Twilit Essentials uses upstream 2.5.0 with these Xbox changes.

- Equip the Spinner with Quick Access after obtaining it. Open Quick Access Edit and assign it to a slot.
- Quick Access uses the specific bottle you select when two bottles hold the same item.
- Learning a scent as Wolf Link preserves the item assigned to the Z slot.
- The no-recenter camera option also works while riding a boar. Dismounting restores the original camera settings.

An older copy of Crests in LocalState or a desktop-only Essentials update will no longer hide the compatible built-in Xbox port. Your saved mod enable settings carry forward.

The official 3.1.3 release contains desktop and mobile binaries. Its Windows plug-in requires the desktop game executable and desktop Windows APIs. A matching source release or compatible Xbox build is still needed for the full 3.1.3 update.

Settings → Video → World Lighting contains the global lighting controls introduced in .756. Dusklight remains at 2.0.3.
